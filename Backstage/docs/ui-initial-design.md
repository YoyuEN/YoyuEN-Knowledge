# Backstage UI 初步设计说明

## 1. 目标
- 建立可扩展的后台基础界面，优先覆盖知识管理与系统权限两条主链路。
- 提供可直接替换为真实接口的页面骨架（筛选、表格、状态、操作）。

## 2. 信息架构
- 仪表盘：整体指标与待处理任务。
- 知识管理：文章管理、分类管理、标签管理。
- 系统设置：用户管理、角色管理、权限管理。
- 数据统计：业务指标与发布漏斗。

## 3. 视觉与交互基线
- 双主题变量：`light-theme`、`dark-theme`。
- 顶栏 + 左侧导航 + 内容区布局，导航支持折叠。
- 统一卡片、表格、工具栏样式，降低跨页面视觉割裂。
- 移动端/窄屏断点：992px 和 768px。

## 4. 文件落点
- 路由：`src/router/router.js`
- 布局：`src/components/Layout.vue`
- 菜单：`src/components/menu.vue`
- 主题与全局样式：`src/composables/useTheme.js`、`src/style.css`
- 页面：`src/views/*.vue`

## 5. 下一步建议
- 对接后端接口：替换页面内静态数组为 API 调用。
- 增加详情页/新建页：文章编辑器、角色授权抽屉、用户编辑弹窗。
- 增加权限守卫：路由级和按钮级鉴权。
- 增加 E2E：覆盖登录、菜单跳转、列表筛选、状态变更。
