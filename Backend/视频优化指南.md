# 视频优化指南

## 🎯 为什么需要压缩视频

未压缩的视频文件通常很大（100MB-500MB），导致：
- ❌ 加载时间长（几分钟）
- ❌ 播放卡顿
- ❌ 浪费服务器带宽
- ❌ 用户体验差

压缩后的视频（20MB-50MB）：
- ✅ 加载快速（几秒）
- ✅ 流畅播放
- ✅ 节省带宽
- ✅ 用户体验好

## 🎬 视频压缩命令

### 方案一：标准压缩（推荐）
适合大多数场景，平衡质量和文件大小

```bash
ffmpeg -i input.mp4 \
  -vf scale=-2:720 \
  -c:v libx264 \
  -crf 23 \
  -preset medium \
  -movflags +faststart \
  -c:a aac \
  -b:a 128k \
  output.mp4
```

**参数说明：**
- `-vf scale=-2:720` - 缩放到 720p（宽度自动）
- `-c:v libx264` - 使用 H.264 编码器
- `-crf 23` - 质量控制（18-28，23是推荐值）
- `-preset medium` - 编码速度（fast/medium/slow）
- `-movflags +faststart` - **关键！** 支持边下载边播放
- `-c:a aac` - 音频编码器
- `-b:a 128k` - 音频码率

**预期效果：**
- 200MB → 30-40MB
- 质量：高清，肉眼几乎无差别

### 方案二：高质量压缩
适合重要视频，保持更高质量

```bash
ffmpeg -i input.mp4 \
  -vf scale=-2:1080 \
  -c:v libx264 \
  -crf 20 \
  -preset slow \
  -movflags +faststart \
  -c:a aac \
  -b:a 192k \
  output.mp4
```

**预期效果：**
- 200MB → 50-70MB
- 质量：非常高

### 方案三：快速压缩
适合网络较慢的场景

```bash
ffmpeg -i input.mp4 \
  -vf scale=-2:480 \
  -c:v libx264 \
  -crf 28 \
  -preset fast \
  -movflags +faststart \
  -c:a aac \
  -b:a 96k \
  output.mp4
```

**预期效果：**
- 200MB → 15-20MB
- 质量：标清，适合移动端

## 📊 批量压缩脚本

### Windows (PowerShell)
```powershell
# 批量压缩当前目录所有 MP4 文件
Get-ChildItem *.mp4 | ForEach-Object {
    $input = $_.FullName
    $output = $_.DirectoryName + "\compressed_" + $_.Name
    
    ffmpeg -i $input `
      -vf scale=-2:720 `
      -c:v libx264 `
      -crf 23 `
      -preset medium `
      -movflags +faststart `
      -c:a aac `
      -b:a 128k `
      $output
    
    Write-Host "已压缩: $($_.Name)"
}
```

### Linux/Mac (Bash)
```bash
#!/bin/bash
# 批量压缩当前目录所有 MP4 文件
for file in *.mp4; do
    output="compressed_${file}"
    
    ffmpeg -i "$file" \
      -vf scale=-2:720 \
      -c:v libx264 \
      -crf 23 \
      -preset medium \
      -movflags +faststart \
      -c:a aac \
      -b:a 128k \
      "$output"
    
    echo "已压缩: $file"
done
```

## 🔍 检查视频信息

### 查看视频详细信息


## 📐 CRF 质量参考

| CRF 值 | 质量 | 文件大小 | 适用场景 |
|--------|------|----------|----------|
| 18 | 极高 | 很大 | 专业视频 |
| 20 | 很高 | 大 | 重要内容 |
| 23 | 高（推荐） | 中等 | 一般使用 |
| 26 | 中等 | 小 | 网络较慢 |
| 28 | 标清 | 很小 | 移动端 |

## 🎯 分辨率建议

| 分辨率 | 适用场景 | 文件大小（参考） |
|--------|----------|------------------|
| 1080p | 桌面端高清 | 40-60MB |
| 720p | 桌面端标准（推荐） | 25-40MB |
| 480p | 移动端/慢速网络 | 15-25MB |
| 360p | 极慢网络 | 10-15MB |

## ⚠️ 注意事项

1. **备份原文件**：压缩前务必备份原视频
2. **测试播放**：压缩后测试播放效果
3. **faststart 必须**：`-movflags +faststart` 是关键参数
4. **不要过度压缩**：CRF 不要超过 28，否则质量太差
5. **音频码率**：128k 对于大多数场景已经足够

## 💡 常见问题

### Q: 压缩需要多长时间？
A: 取决于视频长度和电脑性能，通常 1 分钟视频需要 30 秒到 2 分钟。

### Q: 会损失画质吗？
A: 使用 CRF 23，肉眼几乎看不出差别。

### Q: 可以压缩其他格式吗？
A: 可以，FFmpeg 支持几乎所有视频格式（AVI、MOV、MKV 等）。

### Q: 压缩后视频无法播放？
A: 检查是否添加了 `-movflags +faststart` 参数。
